# FoodGo
## Instrucciones básicas para ejecutar el proyecto

1. Clonar o descargar el repositorio de GitHub.
2. Abrir la carpeta del proyecto en Visual Studio Code.
3. Abrir una terminal dentro de la carpeta del proyecto.
4. Instalar las dependencias ejecutando:

```bash
npm install
```

5. Iniciar el servidor de desarrollo con:

```bash
npm run dev
```

6. Abrir en el navegador la dirección que muestra Vite, por ejemplo:

```text
http://localhost:5173/
```

La aplicación FoodGo se ejecuta de manera local y no requiere conexión a una base de datos.
